# Test Plan

## Scope
- The Smart Parking System project will be tested for functionality, reliability, and usability.

## Objective
- Ensure the system allocates parking spaces correctly and handles queues.

## Features to Test
- Parking allocation
- Queue management
- Error handling
- User input validation

## Responsibilities
- QA team will execute test cases, log bugs, and provide summary.

## Timeline
- Testing will take approximately 2-3 days.
